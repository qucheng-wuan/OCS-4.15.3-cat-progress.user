# OCS-4.15.3-cat-progress.user

为 OCS 网课助手增加小猫定时进度面板，方便查看学习时长。

当前版本：`4.15.3-cat.6`。

## cat.6 更新

- 修复智慧树“AI随堂练习”已提交后弹窗无法自动关闭的问题。
- 弹窗监测独立启动，不再等待桌面通信初始化完成。
- 优先触发页面自身关闭事件，远程点击作为备用；确认弹窗消失后才提示关闭成功。
- 已提交题目跳过再次作答和提交，隐藏弹窗不参与处理。
- 关闭失败后限频提示并重试，远程点击异常不会终止监测循环。
- 保留 cat.5 的 DeepSeek API 状态检测修复。

## cat.5 更新

- 修复 DeepSeek 题库状态检测可能误报“连接超时”的问题。
- DeepSeek 使用带认证的官方 `/models` 接口检测，成功显示“API认证成功🟢”。这表示认证和模型列表访问成功，不代表完整题库查询流程已验证。
- 区分 HTTP 错误、网络失败和真正超过 10 秒的请求；超时后取消检测请求。
- 其他题库检测显示“域名可达🔵”，避免把域名连通性当成查询可用性。
- 保留原有小猫进度面板和其他脚本功能。

## 安装与更新

脚本文件：[OCS-4.15.3-cat-progress.user.js](./OCS-4.15.3-cat-progress.user.js)。

下载最新文件，在脚本猫等脚本管理器中替换原同名脚本，保存后刷新课程页面。

脚本保留原有 `@updateURL none` 和 `@downloadURL none` 设置，因此上传 GitHub 后，已有安装不会自动更新，需要手动替换。

## 验证

通过 JavaScript 语法检查及 11 个状态检测场景测试。Chrome 中安装并刷新后，DeepSeek 显示“API认证成功🟢”；两次实际检测耗时分别为 72 ms 和 79 ms。

cat.6 另通过 7 个弹窗处理场景测试。Chrome 页面自测中，正在运行的脚本自动关闭了测试弹窗一次，弹窗已消失，重复提交次数为 0；当前卡住的真实弹窗也已通过页面自身关闭事件关闭。该自测不代表所有课程弹窗均已验证。
